# 素材查找指南 — 10 分钟内选好

做实操 1（美化清单）和作业时，请放在旁边看。
为了不把时间都花在找素材上，这里整理了**去哪里找 · 用什么词找 · 找多久**。

> 한국어판 → [에셋찾기_가이드.md](에셋찾기_가이드.md)

## 1. 先记住三点

| 约定 | 原因 |
|---|---|
| **从同一个地方选**（来源 1~2 处） | 同一作者 · 同一套件的素材，颜色和造型大多互相一致 |
| **每个物体最多 10 分钟** | 找不到就先用相近的，继续往下做。以后只换 Model 就行 |
| **用英文搜索** | Asset Store 和 Kenney 要用英文搜索才有结果 |

选之前，先写好 **3 个风格关键词**（笔记第 10 周页的第 1 项）。不符合关键词的，再好看也不用。

## 2. 英文搜索词

把“风格词 + 物体词”连起来搜索。例：`low poly tree`、`stylized rock`、`cartoon coin`

**风格词** — `low poly` · `stylized` · `cartoon` · `toon` · `voxel` · `cute`

| 自己游戏里的物体 | 物体词（英文） |
|---|---|
| 收集的东西（金币） | `coin` · `gem` · `crystal` · `star` · `fruit` · `collectible` · `pickup` |
| 要躲避的东西（掉落的石头） | `rock` · `boulder` · `meteor` · `bomb` · `spike` · `barrel` |
| 要击中的东西（靶子） | `target` · `balloon` · `bottle` · `can` · `crate` |
| 钥匙 · 门 | `key` · `door` · `gate` · `chest` · `portal` |
| 敌人（挑战） | `enemy` · `monster` · `slime` · `ghost` · `robot` |
| 角色 | `character` · `robot` · `animal` · `knight` · `astronaut` |
| 地面 | `tile` · `floor` · `ground` · `grass` · `road` |
| 墙 · 边界 | `fence` · `wall` · `hedge` · `cliff` |
| 大装饰物 | `tree` · `rock` · `house` · `building` · `tower` |
| 小装饰物 | `grass` · `flower` · `bush` · `mushroom` · `crate` · `lamp` |

想不出搜索词时，用 [AI 提问模板](简体中文/游戏引擎基础_第10周_AI提问模板.txt) ① **只要搜索词**。AI 说的素材名称 · 网址有时并不存在。

## 3. Kenney — 免费套件（CC0）

[kenney.nl](https://kenney.nl) → **Assets** → **3D**。许可是 **CC0**，使用时无需标注来源（但笔记的美化清单里要写来源）。

| 套件 | 里面有什么 | 适合的游戏 |
|---|---|---|
| [Platformer Kit](https://kenney.nl/assets/platformer-kit) | 平台游戏用的 3D 模型 | 收集 · 钥匙和门 |
| [Nature Kit](https://kenney.nl/assets/nature-kit) | 树 · 石头 · 草 | 户外地图的大装饰物 · 小装饰物 |
| Mini Dungeon | 地牢 · 中世纪风格的模型 | 钥匙 · 逃脱（室内） |
| [City Kit (Roads)](https://kenney.nl/assets/city-kit-roads) | 道路 · 城市街道 | 城市背景的地面 |

Mini Dungeon 请在 kenney.nl 的 Assets 页面按名称查找。

**导入方法**（与第 8 周相同）

1. 在套件页面点 **Download** → 解压 zip
2. 在解压出的文件夹里找到 **FBX** 文件夹
3. 拖到 Unity 的 Project 窗口 `_Project/Models/套件名`
4. 模型显示为白色的话 → 看实操幻灯片“遇到问题时 ①”里**模型是白的**那一行

Kenney 里没有想要的东西时，[quaternius.com](https://quaternius.com) 也免费提供 CC0 的低多边形模型。不过来源越多，风格越容易不一致，所以先定一个套件，只补缺少的。

## 4. Unity Asset Store — 只看免费的

1. 用 Unity 账号登录 [assetstore.unity.com](https://assetstore.unity.com)
2. 在搜索框输入英文搜索词 → **Pricing → Free**
3. 在素材页面确认有 **URP Compatible** 标记
4. **Add to My Assets** → Unity 编辑器 **Window > Package Management > Package Manager** → **My Assets** → **Download** → **Import**

- 导入后模型是**粉色**的 → 看实操幻灯片“遇到问题时 ①”的第一行
- 导入后出现**红色错误** → 删除那个素材的 `Scripts` · `Demo` 文件夹（同一张表的最后一行）

## 5. 选之前确认 — 五项

- [ ] 是否符合 3 个风格关键词
- [ ] 和已经选好的素材放在一起是否协调（低多边形 + 照片般的贴图不要混用）
- [ ] 是否免费 ·（Asset Store 的话）是否 URP Compatible
- [ ] 放在玩家旁边时，大小能否调得协调
- [ ] 是否已在笔记的美化清单里写下**素材名称和来源**

## 6. 一定要遵守

- 从 Asset Store 下载的素材文件**不要上传到公开仓库（GitHub 等）**。
- 实在找不到满意的：只把那个物体做成基础几何体并涂上调色板的颜色，在美化清单里写明原因。
- 放入素材后，**每换一个就 ▶ Play**。
