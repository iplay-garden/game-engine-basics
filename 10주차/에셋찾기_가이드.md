# 에셋 찾기 가이드 — 10분 안에 고르기

실습 1(꾸미기 목록)과 과제를 할 때 옆에 띄워 두세요.
에셋을 찾는 데 시간을 다 쓰지 않도록, **어디서 · 무슨 말로 · 얼마나** 찾을지 정리했습니다.

> 简体中文版 → [素材查找指南.md](素材查找指南.md)

## 1. 먼저 세 가지

| 약속 | 이유 |
|---|---|
| **한 곳에서 고른다** (출처 1~2곳) | 같은 제작자 · 같은 키트의 에셋은 색과 모양이 대체로 서로 맞습니다 |
| **물체 하나에 10분까지** | 못 찾으면 비슷한 것으로 정하고 넘어갑니다. 나중에 Model만 바꾸면 됩니다 |
| **검색어는 영어로** | Asset Store와 Kenney는 영어로 검색해야 결과가 나옵니다 |

고르기 전에 **스타일 키워드 3개**(노트 10주차 페이지 1번)를 먼저 적어 두세요. 키워드에 맞지 않으면 예뻐도 쓰지 않습니다.

## 2. 영어 검색어 모음

스타일 낱말 + 물체 낱말을 붙여서 검색합니다. 예: `low poly tree`, `stylized rock`, `cartoon coin`

**스타일 낱말** — `low poly` · `stylized` · `cartoon` · `toon` · `voxel` · `cute`

| 내 게임의 물체 | 물체 낱말 (영어) |
|---|---|
| 모으는 것 (코인) | `coin` · `gem` · `crystal` · `star` · `fruit` · `collectible` · `pickup` |
| 피하는 것 (떨어지는 돌) | `rock` · `boulder` · `meteor` · `bomb` · `spike` · `barrel` |
| 맞히는 것 (과녁) | `target` · `balloon` · `bottle` · `can` · `crate` |
| 열쇠 · 문 | `key` · `door` · `gate` · `chest` · `portal` |
| 적 (도전) | `enemy` · `monster` · `slime` · `ghost` · `robot` |
| 캐릭터 | `character` · `robot` · `animal` · `knight` · `astronaut` |
| 바닥 | `tile` · `floor` · `ground` · `grass` · `road` |
| 벽 · 경계 | `fence` · `wall` · `hedge` · `cliff` |
| 큰 소품 | `tree` · `rock` · `house` · `building` · `tower` |
| 작은 소품 | `grass` · `flower` · `bush` · `mushroom` · `crate` · `lamp` |

검색어가 떠오르지 않으면 [AI 질문 양식](한국어/게임엔진기초_10주차_AI질문양식.txt) ①로 **검색어만** 받으세요. AI가 말하는 에셋 이름 · 주소는 실제로 없을 수 있습니다.

## 3. Kenney — 무료 키트 (CC0)

[kenney.nl](https://kenney.nl) → **Assets** → **3D** 에서 고릅니다. 라이선스가 **CC0**라서 출처 표기 없이 쓸 수 있습니다(노트의 꾸미기 목록에는 출처를 적습니다).

| 키트 | 들어 있는 것 | 어울리는 게임 |
|---|---|---|
| [Platformer Kit](https://kenney.nl/assets/platformer-kit) | 플랫폼 게임용 3D 모델 묶음 | 모으기 · 열쇠와 문 |
| [Nature Kit](https://kenney.nl/assets/nature-kit) | 나무 · 바위 · 풀 | 야외 맵의 큰 소품 · 작은 소품 |
| Mini Dungeon | 던전 · 중세 분위기의 모델 | 열쇠 · 탈출 (실내) |
| [City Kit (Roads)](https://kenney.nl/assets/city-kit-roads) | 도로 · 도시 길 | 도시 배경의 바닥 |

Mini Dungeon은 kenney.nl의 Assets 화면에서 이름으로 찾으세요.

**가져오는 방법** (8주차와 같음)

1. 키트 페이지에서 **Download** → zip 압축 풀기
2. 압축을 푼 폴더에서 **FBX** 폴더를 찾기
3. Unity의 Project 창 `_Project/Models/키트이름` 으로 끌어다 놓기
4. 모델이 하얗게 보이면 → 실습 슬라이드 '막혔을 때 ①' 의 **모델이 하얗다** 줄

Kenney에 원하는 것이 없으면 [quaternius.com](https://quaternius.com) 도 CC0 로우 폴리 모델을 무료로 나눠 줍니다. 다만 출처가 늘어나면 스타일이 어긋나기 쉬우니, 한 키트로 정한 뒤 모자란 것만 가져오세요.

## 4. Unity Asset Store — 무료만 골라 보기

1. [assetstore.unity.com](https://assetstore.unity.com) 에 Unity 계정으로 로그인
2. 검색창에 영어 검색어 → **Pricing → Free**
3. 에셋 페이지에서 **URP Compatible** 표시 확인
4. **Add to My Assets** → Unity 에디터 **Window > Package Management > Package Manager** → **My Assets** → **Download** → **Import**

- 가져온 뒤 모델이 **분홍색**이면 → 실습 슬라이드 '막혔을 때 ①' 첫 줄
- 가져온 뒤 **빨간 에러**가 나면 → 그 에셋의 `Scripts` · `Demo` 폴더 삭제 (같은 표의 마지막 줄)

## 5. 고르기 전 확인 — 다섯 가지

- [ ] 스타일 키워드 3개에 맞는가
- [ ] 이미 고른 에셋과 나란히 놓았을 때 어울리는가 (로우 폴리 + 사진 같은 텍스처는 섞지 않기)
- [ ] 무료인가 · (Asset Store라면) URP Compatible 인가
- [ ] 플레이어 옆에 세웠을 때 크기를 맞출 수 있는가
- [ ] 노트의 꾸미기 목록에 **에셋 이름과 출처**를 적었는가

## 6. 꼭 지킬 것

- Asset Store에서 받은 에셋 파일은 **공개 저장소(GitHub 등)에 올리지 않습니다.**
- 마음에 드는 것이 끝내 없으면: 그 물체만 기본 도형에 팔레트 색을 입히고, 꾸미기 목록에 이유를 적습니다.
- 에셋을 넣은 뒤에는 **하나 바꿀 때마다 ▶ Play**.
