## 오늘의 순서

| 실습 | 하는 일 |
|---|---|
| 0 · 준비 | Play 씬을 복제해 `Play_Asset` 으로 보관 · ShotKey로 '전' 스크린샷 |
| 1 · 빛 레시피 | 키 비주얼에서 네 가지 읽기 (하늘색 · 해의 높이와 방향 · 그림자 · 따뜻함) → AI 질문 양식 ① 또는 레시피 카드 |
| 2 · 해와 하늘 | Directional Light (Rotation · Color · Intensity · Shadows) → Lighting 창 Environment **Gradient** → 배경색 (선택: 하늘 그림 · 안개) |
| 3 · 화면 효과 | Camera **Post Processing** 체크 → Global Volume → Profile **New** → Tonemapping · Color Adjustments · Bloom · Vignette (값 왼쪽 체크박스!) |
| 4 · 카메라 | Game 뷰 16:9 → 고정형은 **Align With View** · 따라가기형은 Offset · FOV 30~45 |
| 5 · 점검 | KeyVisualPeek(K)로 나란히 · AI 비평 · 한 판 체크 · '후' 스크린샷 (같은 구도) |

## 스크립트

| 부품 | 붙일 곳 | 하는 일 |
|---|---|---|
| ShotKey | 빈 오브젝트 `LookTools` | **P** 키 → 프로젝트 폴더/`Screenshots` 에 화면 저장 (전 · 후 비교용) |
| KeyVisualPeek | 빈 오브젝트 `LookTools` | **K** 키 → 키 비주얼을 오른쪽 위 / 반투명으로 겹쳐 보기 (빌드 전에는 끄기) |
| VolumeToggle | Global Volume | **V** 키 → 화면 효과 켜고 끄기 비교 |
| LightFlicker | Point Light | (도전) 횃불 · 촛불처럼 빛이 흔들림 |

- 9주차 · 10주차 스크립트는 그대로 씁니다. 다시 받지 않아도 됩니다.
- 같은 이름의 스크립트가 두 개 있으면 에러가 납니다. 한국어판과 中文注释版 중 **하나만** 넣으세요.
