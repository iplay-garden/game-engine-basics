# 하늘 그림 4종 · 天空图片 4 张

이 수업을 위해 직접 만든 그림입니다. 기말 프로젝트에 자유롭게 써도 됩니다. · 为本课制作的图片，期末项目可以自由使用。

| 파일 | 분위기 · 氛围 |
|---|---|
| Sky_Day.png | 맑은 낮 · 晴朗白天 |
| Sky_Sunset.png | 노을 · 黄昏 |
| Sky_Night.png | 밤 (별) · 夜晚（星星） |
| Sky_Dawn.png | 새벽 · 파스텔 · 清晨 · 粉彩 |

**쓰는 법 · 用法** (2048 × 1024 파노라마)
1. Project 창에 끌어 넣기 → 그림 선택 → Inspector **Wrap Mode: Clamp** → Apply
2. Project 우클릭 **Create → Material** → Shader **Skybox → Panoramic** → **Spherical (HDR)** 칸에 그림 · Mapping은 **Latitude Longitude Layout**(기본값)
3. **Window → Rendering → Lighting → Environment → Skybox Material** 에 이 재질 · Main Camera **Background Type: Skybox**

1. 拖进 Project 窗口 → 选中图片 → Inspector **Wrap Mode: Clamp** → Apply
2. Project 右键 **Create → Material** → Shader **Skybox → Panoramic** → 图片放进 **Spherical (HDR)** · Mapping 保持 **Latitude Longitude Layout**（默认值）
3. 在 **Window → Rendering → Lighting → Environment → Skybox Material** 放这个材质 · Main Camera **Background Type: Skybox**
