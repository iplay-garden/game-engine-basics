## 2. 스크립트 받기

- 모든 게임 공통: [`스크립트/0_공통/GameManager.cs`](스크립트/0_공통/GameManager.cs)
- 내 게임 폴더의 `.cs` 파일 전부 (위 표의 '스크립트 폴더')
- 中文注释版: [`스크립트/中文注释版`](스크립트/中文注释版) — 全部脚本（含 GameManager）都在这个文件夹

받은 `.cs` 파일은 Unity **Project** 창의 `Assets/_Project/Scripts` 로 끌어 넣습니다.

> 한꺼번에 받기: 저장소 첫 화면 초록색 **Code ▾ → Download ZIP** → 압축을 풀고 `6주차` 폴더 사용

## 3. 발표(10/26) 전 필수 4가지

1. 한 판 완주 — 타이틀 → 플레이 → 결과 → RETRY
2. 화면 3개 — 타이틀 · HUD · 결과
3. 반응 — 득점 · 성공 · 실패에 소리 + 이펙트
4. Windows 빌드 — `.exe` 로 다른 PC에서 실행
