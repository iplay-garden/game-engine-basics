## 이번 과제 (11/9 월 수업 전 · LMS 과제란)

프로젝트 노트(템플릿)를 채워 **PDF 하나**로 제출

1. 기획 1페이지 — AI와 함께 만든 기획을 내 말로 + 크기 점검 + 고른 이유
2. 키 비주얼 — AI로 만든 타이틀 배경 후보 1장 + 스타일 키워드 3개
3. 에셋 목록 — 후보 5개 이상, 그중 3개 이상 가져와 씬에 배치
4. 첫 조작 — 모델을 입힌 플레이어가 움직인다
5. AI 사용 기록 — 3줄 이상 (기획 · 이미지 · 코드 각 1줄)
6. 스크린샷 — Scene 뷰 1장 + Game 뷰(Play 중) 1장
