# 게임엔진기초 9주차 · 회색으로 한 판이 도는 게임

**오늘부터 시작. AI와 에셋으로 한 달간 만들어 보는 게임 프로젝트 — 2단계**
규칙 세 줄(점수 · 성공 · 실패)을 정하고, 회색 도형만으로 타이틀 → 플레이 → 결과 → RETRY가 한 바퀴 도는 게임을 만듭니다. 꾸미기는 다음 주(10주차)부터. 기말 시연 **12/21(월)**.

## 규칙 부품 (스크립트 폴더)

| 부품 | 하는 일 |
|---|---|
| GameManager · ClickHit · EndZone | 6주차와 같은 파일 (한 판의 틀 · 클릭 · 성공/실패 구역) |
| PlayerMove · CameraFollow | 8주차 예시와 같은 파일 — **이미 있으면 다시 받지 마세요** (같은 이름 두 개 = 에러) |
| Collectible | 모으기 — 닿으면 점수, 다 모으면 성공 |
| Hazard · FallingSpawner | 피하기 — 닿으면 실패 · 위에서 계속 떨어뜨리기 |
| ClickTarget | 맞히기 — 클릭하면 점수, 다른 곳으로 이동 |
| KeyItem · GoalDoor | 열쇠를 얻고 문에 닿으면 성공 |
| Chaser | (도전) 플레이어를 천천히 쫓아오는 적 |
