游戏引擎基础 第 9 周 · AI 提问模板（复制后使用）
==================================================

使用方法
1. 把下面的 [基本模板] 整段复制，粘贴到聊天 AI（ChatGPT · Gemini · Claude 等）。
2. 只把（ ）括号里的内容换成自己的。括号可以删掉。
3. [原有脚本] 一栏里粘贴要修改的 .cs 文件全部内容。
   在 Unity 的 Project 窗口双击脚本 → 在编辑器里按 Ctrl + A → Ctrl + C
4. 拿到的代码先用最下面的 [检查七项] 检查后再用。
5. 修改后的代码换个新名字保存。（例：Collectible → CoinScore）
   文件名和代码里的 class 名要完全一样。
   但 GameManager 不要改名，因为其他部件都用这个名字调用它。
   修改前先把原来的 GameManager.cs 复制到桌面等 Unity 项目以外的地方备份。
   （项目里有两个同名 class 会出现 CS0101 错误）


[基本模板] ----------------------------------------- 从这里开始复制

[环境] Unity 6.3 LTS · URP · 英文编辑器 · 只使用 New Input System
[连接] 场景里有 GameManager。请使用下面的函数：
       GameManager.Instance.AddScore(10)  · GameManager.Instance.EndGame(true/false)
       GameManager.IsPlaying（为 false 时什么都不做）· 玩家的 Tag 是 "Player"
[原有脚本]（把要修改的脚本全部粘贴在这里。如果是新建就写“无”）
[想要]（直接写规则句子。例：不是全部收集才成功，而是分数达到 100 以上就成功）
[条件] 新手用 · 每行加中文注释 · 告诉我在 Inspector 里要改什么

----------------------------------------------------- 复制到这里


[想要] 的例子 — 选一个和自己游戏接近的改着用
--------------------------------------------------

（击中）加上输的局 — 原有脚本：GameManager.cs（名字不要改！见上面第 5 条）
  时间到时，分数 100 分以上就成功，不到 100 分就失败。
  目标分数要能在 Inspector 里修改。

（收集）分数不同的金币 — 原有脚本：Collectible.cs
  想让每种金币分数不同。金币 30 分，银币 10 分。
  全部收集就成功的规则保持不变。

（躲避）被砸不马上结束 — 原有脚本：Hazard.cs
  玩家有 3 条命，被砸 3 次才失败。
  剩余的命用 GameManager.Instance.SetInfo("LIFE 3") 这样显示在画面上。

（钥匙 · 逃脱）多把钥匙 — 原有脚本：KeyItem.cs、GoalDoor.cs
  要集齐 3 把钥匙，碰到门才算成功。
  收集的数量用 SetInfo 显示成 "KEY 1/3" 这样。

（通用）加跳跃 — 原有脚本：PlayerMove.cs
  按 Space 向上跳。只有在地面上时才能跳。


[检查七项] — 使用拿到的代码之前
--------------------------------------------------
1. 没有 Input.GetKey · Input.GetAxis            → 有的话说“改成 Keyboard.current”
2. 用 linearVelocity 而不是 velocity            → 不是的话说“改成 Unity 6 的名称”
3. 文件名 = class 名                             → 不一样就改文件名
4. 没有看不懂的行                                → “请解释第○行”
5. ▶ Play 时 Console 没有红色错误               → 复制完整错误再问
6. 用 GameManager.Instance 加分 · 结束           → 不是的话说“请使用 GameManager 的函数”
7. 检查 IsPlaying · 使用 CompareTag("Player")    → 不是的话告诉 AI “在标题画面也会加分”
