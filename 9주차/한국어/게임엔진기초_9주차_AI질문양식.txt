게임엔진기초 9주차 · AI 질문 양식 (복사해서 쓰세요)
==================================================

쓰는 법
1. 아래 [기본 양식]을 통째로 복사해 챗봇(ChatGPT · Gemini · Claude 등)에 붙여 넣습니다.
2. ( ) 괄호 부분만 내 내용으로 바꿉니다. 괄호는 지워도 됩니다.
3. [원래 스크립트] 칸에는 고칠 .cs 파일 내용을 전부 붙여 넣습니다.
   Unity Project 창에서 스크립트를 더블클릭 → 편집기에서 Ctrl + A → Ctrl + C
4. 받은 코드는 맨 아래 [확인 일곱 가지]로 점검한 뒤 씁니다.
5. 고친 코드는 새 이름으로 저장합니다. (예: Collectible → CoinScore)
   이때 파일 이름과 코드 안의 class 이름을 똑같이 맞춥니다.
   단, GameManager는 다른 부품들이 이 이름으로 부르므로 이름을 바꾸지 않습니다.
   고치기 전에 원래 GameManager.cs를 바탕화면 등 Unity 프로젝트 밖에 복사해 두세요.
   (프로젝트 안에 같은 class가 두 개 있으면 CS0101 에러)


[기본 양식] ----------------------------------------- 여기부터 복사

[환경] Unity 6.3 LTS · URP · 영문 에디터 · New Input System만 사용
[연결] 씬에 GameManager가 있어. 아래 함수를 써 줘:
       GameManager.Instance.AddScore(10)  · GameManager.Instance.EndGame(true/false)
       GameManager.IsPlaying (false면 아무것도 안 하기) · 플레이어 Tag는 "Player"
[원래 스크립트] (고칠 스크립트 전체를 여기에 붙여넣기. 새로 만드는 거면 "없음")
[원하는 것] (내 규칙 문장 그대로. 예: 코인을 다 모으면 성공 대신, 점수가 100 이상이면 성공)
[조건] 초보자용 · 줄마다 한국어 주석 · Inspector에서 바꿀 것도 알려 줘

----------------------------------------------------- 여기까지 복사


[원하는 것] 예시 — 내 게임과 가까운 것을 골라 고쳐 쓰세요
--------------------------------------------------

(맞히기) 지는 판 만들기 — 원래 스크립트: GameManager.cs (이름은 그대로! 위 5번 참고)
  시간이 끝났을 때 점수가 100점 이상이면 성공, 100점 미만이면 실패로 끝나게 해 줘.
  목표 점수는 Inspector에서 바꿀 수 있게 해 줘.

(모으기) 점수가 다른 코인 — 원래 스크립트: Collectible.cs
  코인마다 점수를 다르게 하고 싶어. 금 코인 30점, 은 코인 10점.
  다 모으면 성공하는 규칙은 그대로 둬 줘.

(피하기) 맞아도 바로 끝나지 않기 — 원래 스크립트: Hazard.cs
  플레이어 목숨을 3개로 해서, 3번 맞으면 실패로 끝나게 해 줘.
  남은 목숨은 GameManager.Instance.SetInfo("LIFE 3") 처럼 화면에 보여 줘.

(열쇠 · 탈출) 열쇠 여러 개 — 원래 스크립트: KeyItem.cs, GoalDoor.cs
  열쇠 3개를 모두 모아야 문이 성공이 되게 해 줘.
  모은 개수는 SetInfo로 "KEY 1/3" 처럼 보여 줘.

(공통) 점프 추가 — 원래 스크립트: PlayerMove.cs
  Space를 누르면 위로 점프. 바닥에 있을 때만 점프할 수 있게 해 줘.


[확인 일곱 가지] — 받은 코드를 쓰기 전에
--------------------------------------------------
1. Input.GetKey · Input.GetAxis 가 없다          → 있으면 "Keyboard.current로 바꿔 줘"
2. velocity 가 아니라 linearVelocity 를 쓴다      → 아니면 "Unity 6 이름으로 바꿔 줘"
3. 파일 이름 = class 이름                         → 다르면 파일 이름을 맞추기
4. 모르는 줄이 없다                               → "○번째 줄 설명해 줘"
5. ▶ Play 했을 때 Console에 빨간 에러가 없다      → 에러 전체를 복사해서 다시 질문
6. GameManager.Instance 로 점수 · 끝내기를 한다   → 아니면 "GameManager 함수를 써 줘"
7. IsPlaying 확인 · CompareTag("Player") 사용     → 아니면 "타이틀에서도 점수가 올라"라고 알려 주기


AI 사용 기록 (프로젝트 노트에 한 줄씩)
--------------------------------------------------
날짜 | 도구 | 물은 것 | 받은 것 → 내가 바꾼 것 | 배운 것 (내 말로)
